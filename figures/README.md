# Manuscript figures

One script per manuscript figure. Scripts here only **plot** — the heavy
simulation drivers that produced the archived input data live in
[`analysis/`](../analysis). Archived run data live under `data/`; final figure
files land in `figures/output/`.

Run everything from the repository root. Archive-driven scripts work with the
base Python 3 environment; scripts marked **QIIME** rebuild synthetic pools and
must run with the QIIME 2 / Gemelli environment Python:

```bash
QIIME=/opt/miniconda3/envs/qiime2-metagenome-2024.10/bin/python
```

## Provenance notes

- `figure1_workflow.png` is the manuscript's hand-drawn workflow schematic
  (no code generator); it is archived here for completeness.
- `Figure2_corrected.png`, `Figure5_corrected.png`, and
  `Figure8_corrected.png` are the exact manuscript composites. Fig. 2 and
  Fig. 5 were assembled for the manuscript at a 4:3 aspect ratio from the
  script-generated panels (see `figure2_manuscript_panels/`); the scripts
  reproduce the same panel content in their native aspect ratio.
- In the manuscript, Fig. 4 was assembled from panels (a,b) of the archived
  parameter-validation redraw and PCoA triptychs (c,d); the merged script here
  generates all four panels in one figure. Fig. 6 panel annotations in the
  manuscript show exact P values formatted from
  `fig6_metric_3x2_stats.csv`; the script annotates with star levels.
- The current simulation engine caps `edge_fraction` at 1.0 (`"auto"`). Some
  archived outputs were produced with `edge_fraction` 1.1–1.25 under a previous
  engine revision; scripts were updated to the current production default
  (`"auto"`), so regenerated protein-side panels can differ slightly from the
  archived composites. Archived manuscript files are preserved unchanged in
  this directory.
