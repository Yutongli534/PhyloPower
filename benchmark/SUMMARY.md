# Benchmark summary: PhyloPower vs micropower vs MPrESS

## Design

All three tools received the **same** semi-synthetic data: pools of 40 samples
per group generated by PhyloPower's `generate_taxon_pool` from the DPRS
metagenomic pilot data (RCd vs RNi, 10 mice/group, 403 MAGs;
`phylopower/datagene/`), at six effect tiers (`between_scale` = 0, 0.25, 0.5,
0.75, 1.0, 1.5; dilution < 1, baseline = 1, enhancement > 1). For every
(tier, metric) pool the realized PERMANOVA omega-squared (omega2) on the full
pool is the shared effect-size axis; power was estimated at n = 4, 6, 8, 10,
14, 20 per group, alpha = 0.05, 200 replicates per (tool, metric, tier, n).

The omega2 definition (Anderson's distance-matrix sums of squares with the
mean-square-error correction, `phylopower.core.compute_omega2`) was verified
to be **numerically identical** across implementations: PhyloPower, a
from-scratch R reimplementation, and `micropower::calcOmega2` agree to
< 2e-15 on all 12 exported distance matrices
(`results/omega2_validation.csv`).

## How each tool estimates power (methodological differences)

| | micropower 0.4 | MPrESS 1.0.0 | PhyloPower |
|---|---|---|---|
| estimation unit | distance matrix only | OTU table (phyloseq) | feature-level synthetic pool, distances recomputed |
| resampling | bootstrap **with** replacement from the pooled distance matrix (`bootDM`/`bootPower`) | sampling **without** replacement from the OTU table while n <= pool size; Dirichlet-multinomial mixture simulation (`HMP::dirmult`) only when n exceeds the available samples | subsampling **without** replacement from the synthetic pool distance matrix |
| distance computation | consumes pre-computed distance matrices (we supplied skbio Bray-Curtis / weighted UniFrac matrices) | recomputes distances internally through its phyloseq pipeline (`vegdist` Bray-Curtis on proportions; `phyloseq::distance(..., "wunifrac")`, normalized) | skbio Bray-Curtis / `weighted_unifrac(normalized=True)` on the pool count table |
| PERMANOVA engine | legacy `vegan::adonis` (1000 permutations, package default) | legacy `vegan::adonis` (999 permutations, package default) | `skbio.stats.distance.permanova` (199 permutations, seed 20260614) |

Practical consequence: micropower's with-replacement bootstrap can draw the
same pool sample twice, which slightly deflates within-group distances at
larger n and makes micropower mildly optimistic at small effect sizes
(its mean bootstrap omega2 at the near-null tier is ~0.07 vs ~0.03 for the
without-replacement tools). vegan >= 2.7 made `adonis()` defunct, so both R
packages were run through a thin `adonis2()` compatibility shim
(`r/compat_adonis.R`); adonis2 is numerically identical to adonis for a
single-factor design. Because the n grid (<= 20) never exceeded the pool size
(40/group), MPrESS stayed in its sampling branch; its Dirichlet-mixture
simulation branch was not exercised here.

## Concordance of power estimates

Across all 72 (metric, tier, n) combinations (200 replicates each):

| pair | mean \|diff\| | median \|diff\| | max \|diff\| |
|---|---|---|---|
| PhyloPower vs micropower | 0.036 | 0.018 | 0.245 |
| PhyloPower vs MPrESS | 0.018 | 0.007 | 0.095 |
| micropower vs MPrESS | 0.034 | 0.015 | 0.225 |

All maxima occur at the near-null tier (between_scale = 0), where true power
is low and micropower's with-replacement bootstrap bias dominates. Restricting
to the baseline/enhancement tiers (between_scale >= 0.5), every pair agrees
to mean |difference| <= 0.022 and max |difference| <= 0.10.

Realized omega2 per (tier, metric) is effectively identical across tools:
MPrESS's internally recomputed distances give omega2 within ~0.002 of the
shared value for Bray-Curtis and identical values for weighted UniFrac (the
normalized weighted UniFrac is root-invariant, so the midpoint rooting used
on the Python side and phyloseq's rooting agree exactly).

**Minimum n per group for 80% power** (`results/min_n_power80.csv`) agrees
across the three tools exactly or within one grid step at every
(metric, tier) combination. Examples:

| metric | tier (between_scale) | omega2 | PhyloPower | micropower | MPrESS |
|---|---|---|---|---|---|
| Bray-Curtis | 0.5 | 0.117 | 8 | 8 | 8 |
| Bray-Curtis | 1.0 (baseline) | 0.164-0.166 | 6 | 6 | 6 |
| Bray-Curtis | 1.5 | 0.283-0.289 | 4 | 4 | 4 |
| weighted UniFrac | 0.5 | 0.113 | 8 | 8 | 8 |
| weighted UniFrac | 1.0 (baseline) | 0.132 | 8 | 6 | 8 |
| weighted UniFrac | 1.5 | 0.254 | 6 | 6 | 6 |

At the baseline tier (between_scale = 1, the effect size natural to the DPRS
pilot) all three tools therefore give the same sample-size recommendation
within one grid step on both distances.

## Notes for the manuscript

- The benchmark's purpose is validation, not superiority: on conventional
  distances all tools recover the same power-vs-n relationship; differences
  are explained by the resampling mechanism (with- vs without-replacement)
  rather than by the omega2 axis, which was fixed to be identical.
- MPrESS's Dirichlet-multinomial simulation branch only activates when the
  requested n exceeds the number of available samples; a small-pool scenario
  would be needed to exercise it.
- micropower natively speaks Jaccard distances; its support for Bray-Curtis /
  UniFrac here comes from feeding it externally computed distance matrices,
  which is the documented power-estimation entry point (`bootPower`).

## Route A: accuracy of the power estimates themselves (full 30-cell grid)

Protocol: for each cell, the Monte-Carlo **truth** is the rejection rate over
5000 without-replacement draws from the pool distance matrix, each tested with
skbio PERMANOVA (999 permutations, alpha = 0.05; `py/run_truth.py`). Each
tool's **estimate** is one run of its standard workflow (PhyloPower: 200
without-replacement bootstraps, 199 permutations; micropower: `bootPower`
with-replacement bootstrap, 1000 permutations; MPrESS: 200 sampling-branch
replicates, 999 permutations), repeated 50 times with varying seeds
(base 20260614). Full grid: tier {near-null scale 0, dilution scale 0.5,
baseline scale 1.0} x n {4, 6, 8, 10, 14} x {Bray-Curtis, weighted UniFrac}
(30 cells).

Results (`results/accuracy_summary.csv`, `figures/fig_accuracy.png/pdf`):

- **PhyloPower is essentially unbiased**: bias between -0.018 and +0.024
  across all 30 cells (mean |bias| 0.018); residual error is dominated by the
  Monte-Carlo noise of the 200-bootstrap estimate, not bias.
- **MPrESS is comparably unbiased** (bias -0.021 to +0.023; mean |bias|
  0.017), as expected: its sampling branch draws without replacement from the
  same pool, i.e. it targets the same estimand as the truth protocol.
- **micropower systematically overestimates power** (mean |bias| 0.039, max
  +0.224). The bias is concentrated in the near-null tier and grows
  monotonically with n/pool-size on Bray-Curtis: +0.023 (n=4), +0.041 (n=6),
  +0.078 (n=8), +0.105 (n=10; truth 0.108 vs mean estimate 0.214), +0.224
  (n=14; truth 0.177 vs mean estimate 0.401). The same pattern holds on
  weighted UniFrac (up to +0.082) and at the dilution tier (up to +0.057);
  it vanishes only when power is saturated at 1.0. In the decision-relevant
  region (true power 0.1-0.7), micropower can report roughly double the true
  power, leading to systematically underpowered sample-size recommendations.

Interpretation: the with-replacement distance-matrix bootstrap draws
duplicate samples, deflating within-group distances and inflating the
bootstrap omega2 (near-null tier: mean bootstrap omega2 ~0.07 vs true 0.033),
so micropower's power estimates are optimistically biased in proportion to
n/pool-size. Tools whose resampling preserves the pool's sampling
distribution (PhyloPower, MPrESS sampling branch) track the truth.

All 30 truth cells (5000 draws each) and 90 estimate files (50 reps each)
were verified complete; regenerate the summary and figure with
`python3 benchmark/py/summarize_accuracy.py`.

Pattern verification on the full grid:

1. *micropower bias grows with n/pool-size.* Among the 18 unsaturated cells
   (true power < 0.9, where the power ceiling does not mechanically compress
   the bias), micropower's bias increases with n: Spearman rho = 0.574
   (p = 0.013). The cleanest readout is the near-null Bray-Curtis curve, which
   never saturates: bias rises monotonically +0.023 -> +0.041 -> +0.078 ->
   +0.105 -> +0.224 for n = 4, 6, 8, 10, 14. On curves that do saturate, the
   bias peaks at intermediate n and collapses to 0 as true power approaches 1
   (both estimate and truth hit the ceiling), e.g. weighted UniFrac near-null
   peaks at +0.082 (n = 8) before truth reaches 0.94 at n = 14.
2. *PhyloPower and MPrESS show no systematic bias.* Mean signed bias over all
   30 cells: PhyloPower -0.0003 (t-test vs 0: p = 0.86), MPrESS +0.0005
   (p = 0.76); 0/30 cells with |bias| > 0.05 for either tool, vs 8/30 for
   micropower (mean signed bias +0.0365, t-test p < 0.001). Within the
   unsaturated subset the picture is identical (PhyloPower mean bias +0.0014).
