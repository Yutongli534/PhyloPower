# PhyloPower vs micropower vs MPrESS — benchmark

Head-to-head benchmark of **PhyloPower** against two published R tools for
PERMANOVA power analysis of microbiome beta-diversity data:

- **micropower** 0.4 — Kelly et al. 2015, *Bioinformatics* 31:2461
  (<https://github.com/brendankelly/micropower>)
- **MPrESS** 1.0.0 — Alakwaa et al. 2023, *Microorganisms* 11:1166
  (<https://github.com/JCVenterInstitute/MPress>)

All three tools are given the **same input data** (semi-synthetic pools
generated by PhyloPower from the DPRS metagenomic pilot data set,
RCd vs RNi, 10 mice/group, 403 MAGs), the **same realized PERMANOVA
omega-squared (omega2) effect-size axis**, the same per-group sample-size grid
(4, 6, 8, 10, 14, 20) and the same alpha = 0.05. Each tool then estimates power
with its **own native mechanism** (see `SUMMARY.md` for the methodological
comparison).

## Environments

### Python (PhyloPower side)

Base `python3` (3.13.9) with skbio 0.7.2, pandas 2.3.3, numpy 2.3.3,
scipy 1.16.1, matplotlib 3.10.9, joblib. The benchmark uses only conventional
distances (Bray-Curtis, weighted UniFrac), so the QIIME2/Gemelli environment
is **not** required; run everything from the repository root so that
`phylopower/paper_core.py` (the packaged standalone with embedded modules) is
importable. Note: `from phylopower import core` must precede
`import semisynthetic_power` (the embedded meta-path finder must be installed
first), and the bootstrap loop must run with `n_jobs=1` (embedded modules are
not picklable by joblib workers; each bootstrap is ~2 ms anyway).

Dedicated conda env: `/opt/miniconda3/envs/phylopower-r-benchmark`
(R 4.4.3). Packages and versions:

Reproduce the environment (from this machine's conda):

```bash
conda install -n phylopower-r-benchmark -y -c conda-forge -c bioconda \
  r-ape r-phytools r-plyr r-reshape2 r-ggplot2 bioconductor-phyloseq bioconductor-deseq2
conda install -n phylopower-r-benchmark -y -c conda-forge r-rpart r-gplots r-rpart.plot
R=/opt/miniconda3/envs/phylopower-r-benchmark/bin/Rscript
$R -e 'options(repos=c(CRAN="https://cloud.r-project.org")); install.packages("dirmult")'
$R -e 'install.packages("https://cran.r-project.org/src/contrib/Archive/HMP/HMP_2.0.1.tar.gz", repos=NULL, type="source")'
git clone --depth 1 https://github.com/brendankelly/micropower /tmp/micropower_src
git clone --depth 1 https://github.com/JCVenterInstitute/MPress  /tmp/mpress_src
$R -e 'install.packages(c("/tmp/micropower_src","/tmp/mpress_src"), repos=NULL, type="source")'
```

Notes:

- Source compilation inside this conda R env fails (the env references a
  non-existent `arm64-apple-darwin20.0.0-clang`), which is why the compiled
  dependencies were installed as conda binaries. `remotes::install_github()`
  also fails here (stale GitHub PAT in the credential store -> HTTP 401), so
  the two GitHub packages were installed from local clones.
- **adonis shim** (`r/compat_adonis.R`): vegan >= 2.7 made `adonis()` defunct,
  but micropower 0.4 and MPrESS 1.0.0 call the legacy `adonis()` API. The shim
  evaluates the legacy call and delegates to `vegan::adonis2()`, which is
  numerically identical for a single-factor PERMANOVA. It must be sourced
  *before* `library(micropower)` / `library(mpress)` so their import
  environments bind the shim.

## Reproduce the analysis

All commands from the repository root (`phylopower/`):

```bash
# 1. generate semi-synthetic pools, distance matrices, realized omega2
python3 benchmark/py/prepare_pools.py --export

# 2. cross-language omega2 validation (writes results/omega2_validation.csv)
/opt/miniconda3/envs/phylopower-r-benchmark/bin/Rscript benchmark/r/validate_omega2.R

# 3. power curves (PhyloPower ~1 min; micropower ~10 min; MPrESS ~15 min on 4 cores)
python3 benchmark/py/run_phylopower_power.py
/opt/miniconda3/envs/phylopower-r-benchmark/bin/Rscript benchmark/r/run_micropower.R
/opt/miniconda3/envs/phylopower-r-benchmark/bin/Rscript benchmark/r/run_mpress.R

# 4. combined CSV, min-n(80%) table, figure
python3 benchmark/py/plot_benchmark.py
```

## Design parameters

| parameter | value |
|---|---|
| pilot data | `phylopower/datagene/` DPRS (RCd vs RNi, 10/group, 403 MAGs) |
| pool generation | `semisynthetic_power.generate_taxon_pool`, pool = 40/group, seed 20260614, residual_scale = 1, noise_multiplier = 0.10 |
| effect tiers (between_scale) | 0, 0.25, 0.5, 0.75, 1.0, 1.5 (dilution < 1, baseline = 1, enhancement > 1) |
| distances | Bray-Curtis (skbio), weighted UniFrac (skbio `weighted_unifrac`, normalized = TRUE, midpoint-rooted tree) |
| n per group | 4, 6, 8, 10, 14, 20 |
| alpha | 0.05 |
| replicates per combo | 200 for all three tools |
| PhyloPower | bootstrap (without replacement from pool) = 200, permutations = 199, seed 20260614 |
| micropower | `bootPower`, boot_number = 200, PERMANOVA via legacy adonis (1000 permutations, package default) |
| MPrESS | sampling branch (without replacement, pool 40 >= n), distances via its own phyloseq pipeline, PERMANOVA via legacy adonis (999 permutations, package default); realized omega2 per tier recomputed from its own distances (reported in the CSV; `mean_boot_omega2` is NA because MPrESS has no bootstrap-omega2 concept) |

Runtimes on this machine: PhyloPower ~1 min, micropower ~15 min, MPrESS ~30 min (4 cores each for the two R tools).

The realized omega2 of every (tier, metric) pool was computed identically on
all sides; the cross-language validation (`results/omega2_validation.csv`)
agrees to < 2e-15 between PhyloPower's `compute_omega2`, a from-scratch R
reimplementation, and `micropower::calcOmega2`.

## Route A: accuracy benchmark (estimates vs Monte-Carlo truth)

Route A asks not "how much power" but "whose power *estimate* is closest to
the truth". Truth per cell = rejection rate over 5000 without-replacement
draws from the pool distance matrix under skbio PERMANOVA (999 permutations,
alpha = 0.05). Each tool contributes 50 independent standard-workflow
estimates per cell (same internal settings as the Route-B curve runs).
Scripts: `py/run_truth.py`, `py/run_accuracy_phylopower.py`,
`r/run_accuracy_micropower.R`, `r/run_accuracy_mpress.R`,
`py/summarize_accuracy.py`. Grids: `--grid pilot` (tier {0, 1.0} x n {6, 10})
and `--grid extended` (tier {0, 0.5, 1.0} x n {4, 6, 8, 10, 14}).

```bash
python3 benchmark/py/run_truth.py --grid pilot --jobs 4
python3 benchmark/py/run_accuracy_phylopower.py --grid pilot
$R benchmark/r/run_accuracy_micropower.R pilot
$R benchmark/r/run_accuracy_mpress.R pilot
python3 benchmark/py/summarize_accuracy.py   # merges shards, bias/RMSE table, figure
```

Outputs: `results/accuracy_truth*.csv`, `results/accuracy_estimates*/`
(per-cell shards) + `accuracy_estimates_long.csv`,
`results/accuracy_summary.csv`, `figures/fig_accuracy.{png,pdf}`.
Findings are summarized in `SUMMARY.md` ("Route A" section).
